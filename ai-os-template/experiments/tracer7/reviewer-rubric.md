# Tracer 7 blinded candidate rubric

Review only the assigned candidate label. Do not infer or request model identity,
transcript, timing, or run order.

1. Reproduce D0 and candidate identities at start.
2. Enumerate all reachable effect surfaces before judgment and reconcile them with the
   frozen inventory and scoped invariant selection.
3. Return a verdict for every assigned requirement and invariant: pass, fail, or
   unverifiable, with executable evidence.
4. Findings require stable IDs, severity, file:line, concrete failure, reproduction,
   and fix direction. Separate design incompleteness from implementation defects.
5. Reproduce the candidate identity at finish. A mismatch invalidates the packet.

Score independently before seeing another lens: deterministic correctness, security
and authority preservation, architecture fidelity, test quality, scope discipline,
maintainability, and residual confidence. Do not reward stylistic familiarity.
